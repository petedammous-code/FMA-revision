  3. Soit q = (qj )j∈Z une suite de points de Rn , et soit δ > 0. Si p = (pj )j∈Z est une suite de
     points de Rn , on dit que p est une δ-filature de q (pour φ) si l’on a ∥pj − qj ∥ ≤ δ pour tout
     j ∈ Z et si p est de plus une orbite de φ, c’est-à-dire vérifie pj+1 = φ(pj ) pour tout j ∈ Z.

      Le but de cette question est de démontrer l’assertion suivante :

                             Si δ > 0 est suffisamment petit, il existe ε > 0 tel que
                        toute ε-pseudo-orbite de φ dans Λ admet une unique δ-filature.

      Pour tout r > 0, notons B(r) la boule fermée de centre 0 et de rayon r dans l’espace normé
      V. Fixons par ailleurs un nombre α ∈]0, 1[ vérifiant α∥Θ−1 ∥ < 12 , où ∥Θ−1 ∥ est la norme
      d’opérateur de l’application Θ−1 : V → V définie en 2(c).
      Fixons un nombre ε > 0, ainsi qu’une ε-pseudo-orbite q = (qj )j∈Z de φ dans Λ.

       (a) Soit r > 0 et soit F une application de B(r) dans V. On suppose que F est α-
           lipschitzienne et vérifie ∥F (0)∥ ≤ α r. Démontrer que l’application G = Θ−1 ◦ F vérifie
           G(B(r)) ⊂ B(r), puis qu’elle admet un unique point fixe x0 dans B(r), qui vérifie de
           plus ∥x0 ∥ ≤ 2∥Θ−1 ∥∥F (0)∥.
       (b) Pour tout j ∈ Z, définissons fj : Rn → Rn par fj (h) = φ(qj + h) − qj+1 − dφqj (h). Si
           x = (xj )j∈Z est un élément de V, posons F (x) = (fj−1 (xj−1 ))j∈Z . Démontrer que x
           est un point fixe de Θ−1 ◦ F si et seulement si la suite q + x est une orbite de φ.
